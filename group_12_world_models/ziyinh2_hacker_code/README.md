Uncertainty-Aware Navigation with World Models 🛡️Course Project | [CS598]TL;DR: This project implements zero-shot uncertainty extraction for the Navigation World Model (NWM) (CVPR 2025). By hacking the inference pipeline, we achieve real-time risk assessment and hallucination detection without retraining the 1B-parameter model.🎯 Project GoalStandard world models are powerful simulators but suffer from Safety Bias—they often hallucinate safe paths even when facing inevitable collisions. This project introduces three inference-time methods to detect when the model is uncertain or unsafe:Spatial Uncertainty (Latent Variance): A 5x faster method to detect navigation complexity.Semantic Consistency (Hallucination Detector): Using a ResNet judge to detect Mode Collapse.Active Safety (Constraint Checker): A visual classifier to predict "Crash Probability."🛠️ Setup & InstallationTo run this project, you will need a GPU (tested on NVIDIA A100/H100, but should work on RTX 3090/4090).
