================================================================================
GO-WITH-THE-FLOW MOTION TRANSFER PIPELINE - COMPLETE GUIDE
================================================================================

OVERVIEW
--------
Transfer motion patterns from one video to generate completely new videos
with the same dynamics but different visual content.

TWO-STEP PROCESS
----------------

STEP 1: Extract Motion (flow_warp environment)
  Tool: make_warped_noise.py
  Input: Video file or URL
  Output: Warped noise (motion representation)
  Time: ~1-3 minutes

STEP 2: Generate Video (flow environment)
  Tool: cut_and_drag_inference.py
  Input: Warped noise + Text prompt (or image)
  Output: New video with transferred motion
  Time: ~5-15 minutes

================================================================================
PARAMETERS GUIDE
================================================================================

make_warped_noise.py
--------------------
Required:
  <video_path>        Path or URL to source video
  --output_folder     Where to save results

What it does:
  - Resizes video to 480x720, 49 frames
  - Extracts optical flow using RAFT
  - Creates warped noise representation
  - Saves visualization and flow data

Output files:
  noises.npy         Main output (warped noise)
  flows_dxdy.npy     Optical flow fields
  input.mp4          Preprocessed video
  first_frame.png    Reference frame
  noise_video.mp4    Visualization

cut_and_drag_inference.py
--------------------------
Required:
  <noise_folder>      Folder with warped noise

Key options:
  --prompt            Text description (T2V mode)
  --image_path        Starting image (I2V mode)
  --output_mp4_path   Output filename
  --device            cuda or cpu
  --num_inference_steps  Quality (20=fast, 50=high)
  --degradation       Motion strength (0.0=full, 1.0=none)

Models available:
  I2V5B (default)     Image-to-Video, 5B params
  T2V5B               Text-to-Video, 5B params
  T2V2B               Text-to-Video, 2B params (faster)

================================================================================
DEGRADATION CONTROL
================================================================================

Control how much motion is transferred:

--degradation 0.0    Full motion transfer (recommended)
                     Output follows input motion exactly

--degradation 0.3    Mostly motion (70% input, 30% random)
                     Slight variation from input

--degradation 0.5    Balanced (50% input, 50% random)
                     Mix of structure and freedom

--degradation 0.7    Mostly random (30% input, 70% random)
                     Loose motion reference

--degradation 1.0    No motion transfer
                     Completely random, no input motion

Formula: output = (1 - deg) × warped + deg × random

ENVIRONMENT SETUP
================================================================================

TWO CONDA ENVIRONMENTS REQUIRED:

1. flow_warp (for motion extraction)
   - Contains: rp, CommonSource, RAFT model
   - Used for: make_warped_noise.py, extract_flow_sequence.py
   - GPU: ~2-4GB for optical flow

2. flow (for video generation)
   - Contains: diffusers, CogVideoX models
   - Used for: cut_and_drag_inference.py
   - GPU: ~8-16GB for generation

Activate the correct environment for each step!

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "output_folder already exists"
Fix: Delete folder or use different name
  rm -rf my_motion
  python make_warped_noise.py video.mp4 --output_folder my_motion_v2

Issue: CUDA out of memory
Fix: Reduce inference steps or use smaller model
  --num_inference_steps 15
  --model_name "T2V2B"

Issue: "No module named 'rp'"
Fix: Install in flow_warp environment
  conda activate flow_warp
  pip install rp

Issue: Video quality poor
Fix: Increase steps, adjust degradation
  --num_inference_steps 50
  --degradation 0.0

Issue: Motion not transferring well
Fix: Check degradation, verify flow extraction worked
  --degradation 0.0  # Full motion
  ls <folder>/noises.npy  # Verify exists
