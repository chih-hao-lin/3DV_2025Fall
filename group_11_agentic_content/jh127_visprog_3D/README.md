# Visual Programming 3D
### Hacker: Jiaheng Han (jh127@illinois.edu)

### Setup

``` bash
cd visprog_3d
conda env create -f environment.yaml
conda activate visprog
```

-   After creating the environment, install **VGGT** by following the
    instructions in the official repository:
    https://github.com/facebookresearch/vggt
-   An **OpenAI API key** is required to run the demo. Add your key in
    `notebooks/demo_3d.py` (line 7).

------------------------------------------------------------------------

### How to run?
``` bash
cd notebooks
python demo_3d.py
```

Running the script will generate a visualization file named
**`demo_3d_debug.html`**.

Example results can be found in the `sample_output` folder.

### Technical Details
Our goal is to extend visual programming capabilities to **3D
reasoning**. To support this, we introduce **7 new modules** added
to the original visprog module list (see
`visprog_3d/engine/step_interpreters.py`):

-   **ReconInterpreter**\
    Reconstructs point clouds from multi-view RGB images. The output is
    a list of point clouds generated by projecting pixels using depth
    maps predicted by VGGT.

-   **BoundInterpreter**\
    Computes the bounding box of a point cloud.

-   **IndexInterpreter**\
    Indexes into a list of images or point clouds.

-   **SelectPCInterpreter**\
    Selects a subset of points from a point cloud using mask images.

-   **RemovePCInterpreter**\
    Removes a subset of points from a point cloud using mask images.

-   **MergePCInterpreter**\
    Merges two point clouds.

-   **DistPCInterpreter**\
    Computes the distance between two point clouds, defined as the
    distance between their respective centers.

Example question--answer pairs for these modules are provided in
`visprog_3d/prompts/threedv.py` as references for LLM prompting.
