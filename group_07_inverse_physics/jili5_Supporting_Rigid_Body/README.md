# Supporting Rigid-body in PAC-NeRF

This repo is build upon the official implementation of [PAC-NeRF](https://github.com/xuan-li/PAC-NeRF).

## Installation

Follow the official README to install the necessary packages. Note that some packages might need to be installed with their own methods (e.g., mmcv). The torch version used by the author is `2.5.1+cu118`.

## Run

Use `run.sh` to run all experiments shown in the demo.
